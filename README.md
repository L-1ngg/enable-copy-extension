# Enable Copy - 解除复制限制

一个 Chrome / Edge 浏览器扩展（Manifest V3），用于解除网页对复制、选择、右键菜单和快捷键的限制。

## 功能

- 恢复文本选择（覆盖 `user-select: none`）
- 恢复右键菜单（拦截 `contextmenu` 阻止逻辑）
- 恢复复制 / 剪切（拦截 `copy` / `cut` 劫持，防止粘贴时附加追踪文字）
- 恢复快捷键（Ctrl/Cmd + C、X、A、S、U、P 及 F12）
- 对 iframe 内嵌内容同样生效
- 弹窗一键全局开关

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录
4. 点击工具栏图标可打开/关闭功能

## 验证

用浏览器打开本目录下的 `test-page.html`，该页面模拟了五种常见防复制手段：

- 扩展关闭时：无法选中、右键被拦截、粘贴带追踪文字
- 扩展开启时（如切换开关前页面已打开，刷新一次）：全部恢复正常

## 原理

内容脚本在 `document_start` 注入，早于页面脚本注册事件监听器。在 `window` 捕获阶段对
`contextmenu` / `copy` / `cut` / `selectstart` / `select` 调用 `stopImmediatePropagation()`，
使事件根本到不了页面的处理函数，浏览器默认行为（选择、复制、右键菜单）自然恢复；
同时注入 `user-select: auto !important` 样式覆盖 CSS 限制。只拦截与复制相关的键盘快捷键，
不影响页面其他键盘交互。

## 局限

- 对 `chrome://` 页面、Chrome 应用商店、内置 PDF 查看器无效（浏览器安全限制，所有扩展皆然）
- 图片 / Canvas 渲染的文字（如百度文库）不是真实文本，请配合截图 OCR
- 字体混淆站点（复制出乱码）属于字符映射问题，同样需要 OCR
- 切换开关后，已打开的页面立即生效；若个别页面把监听器挂在 `window` 上且注册更早，刷新页面即可
